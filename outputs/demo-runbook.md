## The single sentence

A consulting firm can share its expertise while its agents build different, tested software from each client's confidential requirements, without carrying one client's context into another engagement.

## Timing decisions

The script has room for actions but does not promise vendor latency. If the live generation takes too long, shorten commentary and use an explicitly labeled time cut in the video. For a live presentation, start the generation at the beginning and explain the boundaries while it runs.

Do not add a policy-change/rebuild sequence to this version: no such control is implemented. Do not claim arbitrary code generation: the model authors a bounded workflow, and a deterministic compiler emits the executable application. Do not claim an authenticated corporate approval system: the generated form demonstrates routing behavior.

The fresh worker may already have retrieved its new client's sources by the next UI refresh. Show its new run ID and actual source manifest; do not promise to capture a transient empty state. Previously delivered artifacts remain in their original client. A retained ready artifact whose originating run is retired cannot newly deliver.

## Expected behavior, for the presenter

The common visible input is $75,000. Beacon's synthetic threshold is $50,000: at or above it, Procurement plus CFO. Crest's synthetic threshold is $100,000: below it, Department Manager. Expected cases are authored independently of generation and withheld from the model. Read the actual cards and test outcomes before narrating success; do not narrate these expectations over a failing run.

The deliberate wrong-client attachment is an operator-triggered boundary test, not a claimed autonomous jailbreak. The privileged operator sees both clients; the worker model contexts do not receive that combined operator view. Downloaded artifacts retain their client-specific information and cannot be recalled from recipients.
