# Purchase approval policy

All amounts are in USD. Below the threshold specified in the restricted appendix, the only required approver is Department Manager. At or above that threshold, the only required approver is Procurement. Department Manager is not included in the escalated sequence. CFO is not an approver under this policy.

The threshold is intentionally absent from this document. Read this engagement's restricted appendix before producing an executable workflow. The exact role names are Department Manager and Procurement. No additional approval roles are authorized by this policy.
